
**# Code Roaster**

An architectural-blueprint themed single-page code critique app. Paste a snippet, choose a language and roast level, then receive a structured Hinglish critique and corrected code through Gemini.

**## Run locally**

1\. Install dependencies: \`npm install\`

2\. Copy \`.env.example\` to \`.env.local\` and enter your own Gemini API key.

3\. Run \`npm run dev\`, then open \`[http://localhost:3000](http://localhost:3000)\`.

Optional: run \`npm run check\:api\` after adding your key to test the server integration.

The key is only read by \`lib/gemini.ts\` on the server and is excluded from git.
